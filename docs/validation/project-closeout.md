## 保留项及能力边界

- 原有 `hosts/lifecycle.py` 的 os 和 `operations.py` 的 Path 属于未使用导入候选，核对后不影响运行；本轮记录而不顺手清理无关旧代码，没有将它们冒称功能性死模块。
- iterm2 依赖导入时可能出现 websockets legacy 的弃用提示，项目原生连接使用 asyncio API；本轮未扩大依赖升级，不把提示当作本项目接口故障。
- 项目发行许可证尚未选择，沿用已有协议基线中的明确说明；本轮不代替本人决定许可证，不作法律兼容性结论。
- 未知历史及去重证据按既有保留政策保护，不能以释放占用为由自动删除。原生证据不可达、不完整或超出有界范围时仍保守阻塞，但给出具体原因和正式处置入口。
- 占用不是全机文件锁，独立客户端可自行发起任务；原生 interrupted／终态不能证明所有未登记系统子进程均已退出。已知未结束工具会阻止释放。
- 自然上下文失效触发、Mac 完整排版与复制、同消息图文仍是原有后置范围，本轮不改写为支持。
