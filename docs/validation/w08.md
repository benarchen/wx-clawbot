进入真实项目前读取各自规范与 Git 状态，再用正式可见启动模块创建两个专用 iTerm2 会话。两项目各完成桌面分析并记忆随机标记、桥接无提示追问、桌面再次无提示追问，共六条 completed turn。端点、PID／微秒启动时间／TTY、runtime、native thread／session 均复验一致，两个标记互不混入；任何用户工作终端均未接收输入。
