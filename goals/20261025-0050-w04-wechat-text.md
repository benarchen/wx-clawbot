## 决策、边界与依赖

- Python、asyncio、标准库 HTTP 与 SQLite；优先现有依赖，不安装完整 Gateway 或全局依赖。
- 允许新增 `src/wx_clawbot/channels/`、对应测试、脱敏 fixtures、配置模板、CLI 登录／文本诊断与使用文档。该目录负责通道，不执行 Agent 任务或擅自选择 thread。
- 不读取其他项目微信凭据或服务，不迁移旧绑定，不停止服务。真实凭据仅写本项目独立私有目录，目录 0700、敏感文件 0600，绝不入 Git。
- 扫码由本人完成；明确确认本人测试账号和联调对象后，只向该对象进行必要测试收发。若二维码要求替换既有绑定，先核对具体影响。

- 不修改 Codex 全局配置、模型、认证、Skills 或插件；继续使用本人已接受的配置新基线。

## 检查点

1. 逐字段核对登录、轮询、发送、公共 headers、版本编码与客户端标识适用条件；记录固定源码及实际响应差异。
2. 实现有限超时和响应上界的 HTTP 客户端，登录前后鉴权分离；长轮询与发送使用独立有界资源。禁止 token 随跨源重定向泄漏。
3. 实现二维码状态、私有凭据、本人身份绑定；未知身份、错会话、重复消息、缺失／过期上下文及未知消息类型明确处理。
4. 游标与接收去重按事务保存，发送重试不重新执行任务；不把发送 client ID 当作已证明的服务端幂等保证。
5. 单元和协议测试覆盖真实字段、无效输入、错误与资源边界；显式本人联调核对真实收发、游标、去重与上下文，输出脱敏 V06 证据。

## 验证方法与关键失败路径

普通测试使用本地合成 HTTP 对端和临时状态，不自动连接微信或用户终端。覆盖 HTTP 错误与业务错误、超大响应、无效 JSON、错误服务地址、身份不匹配、消息缺少稳定 ID、连续相同文本的不同消息、长轮询断连和关闭超时。所有不确定发送保持 unknown，不伪报成功。

真实登录与联调显式执行，不输出 token、完整 payload、二维码密钥或私人消息到公开报告。W04 不将本地模拟或扫码成功当作真实文本闭环，也不宣称已实现 W05 路由或 W06 的全部执行恢复。
