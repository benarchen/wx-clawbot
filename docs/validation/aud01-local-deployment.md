# AUD01：0.1.4 本机切换

记录时间：2026-11-05 21:47（北京时间）。

本机已按本人明确授权从独立 0.1.3 切换至已发布的独立非 editable 0.1.4，schema 保持 6。准确时间、摘要和检查结果见[机器记录](aud01-local-deployment.json)；对应[Git 版本交付](aud01-publication.md)、[工程验收](native-diagnostics-rules.md)及[切换操作卡](../operations.md#eng01独立运行制品与开发隔离)。

## 操作与验收

切换前活动任务、有效占用、待发回执、发送中尝试、同步交互及有效异步问题均为零。两条历史 unknown 保留，不视作可重放任务。原消费者以退出码 0 正常停止，在维护锁下完成 13 张业务表的一致性备份，完整性及外键检查通过。

复用已通过 702 项回归的冻结 wheel；新建版本目录，不覆盖旧版或重新构建不同制品。原 Label 仅执行一次 bootout／bootstrap，只替换 ProgramArguments 和 WorkingDirectory，其他托管字段保持；账本、配置、凭据和 Codex 全局设置不变。预检曾因 macOS 将解释器显示为底层 Python.app 路径而拒绝，核对准确进程身份、manifest 和已加载摘要后通过，未因此停止服务或放宽版本校验。

从请求正常停止到完成新实例验收共 26.119 秒。新实际进程 argv／cwd、managed 与 foreground 身份、launchd PID、manifest 及源码摘要一致，唯一消费者、supervision running、host／native ready。父进程和携带同一 manifest 的隔离渲染子进程已实际验证，生成 5 段测试文本；测试不连接微信或原生任务队列。

12 张非路由业务表与停服备份逐行一致；路由仅允许正常恢复的 revision／时间更新，原角色、目标和项目保持。568 条既有回执及两条 unknown 未改写；配置、凭据、Codex 全局配置及原生进程保护检查通过。日志核对新实例仅有一次 process_start，不通过人为断开生产连接验证日志。

本轮无 schema 迁移、数据恢复、原生任务提交或额外微信测试发送；未操作微信客户端，未重启 Codex、iTerm2 或其他项目服务。运行恢复后的自然业务行为仍由原契约处理，本记录不等同于新一轮手机收件验收。

## 恢复与交接

旧 0.1.3 版本目录、原 plist 和私有账本备份保留。若后续需要恢复服务版本，先正常停止唯一消费者，再按原 Label 和备份托管参数切回兼容 schema 6 的旧独立制品；保留当前账本及新增写入，不使用旧备份覆盖数据，不清理 unknown 或重放任务。

原始进程身份、路径、plist、账本备份和现场记录仅保存在本次私有临时目录，正式文档不依赖它们运行。新旧制品的保留／清理另按项目规则处理。本轮只完成已授权本机切换及文档同步，没有再次提交、打 tag 或推送。
