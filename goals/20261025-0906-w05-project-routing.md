# W05：项目、会话路由与可见启动

## 目标与预期行为

本人通过微信选择注册项目、查找与切换原生会话、单次发送或持续聚焦，并在 iTerm2 创建可见、可操作的新 Codex 会话。列表序号有明确快照，接收时冻结任务目标；失败不改变原路由或产生虚假成功。通过 P02 至 P06 与 V05 对应验证后交付。

## 背景与文件入口

依赖已验收 W02／W03 与已阶段交付 W04。阅读 [施工清单](implementation-plan.md)、[产品](../docs/product-design.md)、[架构第 5／6 节](../docs/architecture-design.md)、[开发契约第 4 节](../docs/development-contracts.md)、[桌面队列](../docs/desktop-queue-contract.md)。现有入口为 `config.py`、`sessions.py`、`hosts/`、`agents/codex.py`、`agents/queue.py`、`interactions.py` 与 `channels/`。

## 已确定决策与依赖

- 原终端、进程、运行时与 thread 必须有可信关联；目录、标题或存档历史不能代替身份。先检查原生字段可否自动关联，不可证明时采用明确的首次绑定，不伪称自动发现已完成绑定。
- 同进程原生 `/new` 真实反例已确认，派发须被动读取当前 TUI 页脚 ID 并核对 native thread。本人明确授权仅在 Codex 全局 `tui.status_line` 首位新增 `session-id`，保留原 5 项及顺序；这是本次施工的一次性配置例外，不是桥接程序自动改全局配置的能力。
- `/cd` 复用该项目和目录的受管会话，没有则可见创建；跨目录使用另一 thread，不改变旧会话 cwd。相对路径基于当前选中目录，符号链接真实解析后必须在注册范围内。
- 本人已明确选择独立观察订阅：focus 是普通消息执行目标；attach 是桌面主动任务的进展、结果和交互订阅；detach 只取消订阅。每个微信绑定最多一份独立观察订阅，重复同目标 attach 幂等，替换时明确回显。不得以只修改本地标记冒充原生订阅成功。
- 忙碌普通任务使用 W03 原生 daemon 队列，停止、状态及交互答复不排在普通任务后面。未知提交不得自动重放。
- 启动先保存 launch_id 与意图，再调用 iTerm2；重复或重启后不重复启动。可见端点与同运行时 native thread 核验完成后才 ready。
- 自然过期上下文已由本人明确转入 W08，不在本 Goal 伪报其通过。W06 继续负责完整任务账本、Outbox 和崩溃恢复，W07 负责最终前台运维入口；本 Goal 必须交付可运行的命令链路。

## 修改范围与禁止事项

允许增加命令解析、项目路由、原生会话目录、受控可见启动与必要的启动私有登记，接入既有 Agent／通道并补充测试和文档。使用项目内虚拟环境，不默认新增依赖，不委派。

除上述明确授权的单字段显示项外，不修改 Codex 全局配置、模型、认证、Skills、插件或系统设置；不关闭用户终端、不向工作终端注入测试、不读取其他项目凭据或服务。与 openclaw-local 完全独立。真实配置、身份、消息、SQLite、日志和临时验收数据不得入 Git。

## 检查点

1. 完成原生身份关联与启动 SDK 入口复核；确定私有注册配置和首次绑定过程，保留无法自动核验的真实状态。
2. 固定命令解析与别名，交付 projects、cd、sessions／ss、send／s、focus／f、unfocus／uf、new、status、stop、approve、deny、answer、help，以及已确认的 attach／a、detach／ua。
3. 实现列表快照、有效期、路由 revision 与冻结目标；列表刷新／过期、退出聚焦、跨项目切换和控制命令具有明确行为。
4. 实现一次可见启动、握手、ready／starting／unknown／failed 及恢复核对；恶意路径不触发 Shell 展开，重复请求只对应一个终端。
5. 用两个临时项目与专用终端执行发现、切换、发任务、观察订阅、可见新建及重复启动真实验证；按授权本人微信联调命令入口。真实项目最终只读架构和规则延续验收保留 W08。

## 测试方法与关键失败路径

离线测试检查解析错误、未知命令、无目标、旧列表、符号链接越界、目标退出或进程重用、路由在异步操作中变化、订阅失败回滚、重复启动、启动回执丢失及取消等待后的未知状态。普通测试不得连接微信或用户终端。

真实接口测试显式执行，限制在两份专用临时项目和任务所属终端。核对 SDK 可见端点、原生 thread、运行时和 cwd，核对命令到实际 turn 及结果；同目录多会话不能猜测匹配。测试窗口里创建的会话可用于可见操作检查，不修改 guixu 内容。

## 验收标准

P02 至 P06、V05 在本 Goal 对应的 fixture 与本人微信命令流程有实际证据；命令不能把仅接收入队、仅打开终端或本地路由变化称为任务完成。独立 attach／detach 的输入路由与订阅互不混淆；必要交互保持原请求身份。非零测试、编译和公开内容检查通过，文档可独立使用。未完成 W06／W07 能力明确标识，不提前宣布完整首版通过。
