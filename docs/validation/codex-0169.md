## 协议与实现

官方 daemon version 当前实际报告 managed／app-server 为 0.169.0；从该准确 managed 可执行文件生成 479 份实验 schema，与 CLI 生成文件一致。对照上次 0.167.0 的 43 份桥接相关契约，18 份结构有变化，无缺失；逐文件原始摘要及变化路径见 [比较证据](codex-0169.json)。该结果纠正了早一轮发现失败后的不可用快照，不能推定 daemon 曾经停止，也不以 CLI 版本代替 daemon 证据。

| 变化 | 本次处理 |
| --- | --- |
| 模型目录增加 modelProvider | 所选会话的设置／Fast／status 按其准确 provider 读目录；不切 provider，旧版本不发送新字段 |
| 会话列表增加账号／附属关系过滤 | 0.169.0 指定当前账号、不含附属 thread；直接 inspect 拒绝附属对象，避免作为独立会话派发 |
| agentMessage 增加 moderation／display | 缺失或明确 unmoderated 且无 display 时保留文本；其他仅提示到原生客户端查看，完整正文及错误正文均不透传 |
| settings 增加 environments | 不发送新字段；模型／推理／tier 契约不扩大为环境管理，保持原生省略语义 |
| queue 增加可选 client metadata | 不发送，不改变准确 thread／client ID 及未知不重放 |
| 新增 inferenceHookDenied／工具输出内容／contentTokenCount | 不自动重跑被拒请求、不扩大输入模态、不估算 Context 百分比 |

0.169.0 的图片输入及异步问题专项保持关闭。旧版本已经验收的能力和历史结果保留其范围，不因新版本字段相近自动继承动态通过。
